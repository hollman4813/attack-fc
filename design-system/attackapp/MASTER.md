# AttackApp 디자인 시스템 (MASTER)

ATTACK F.C. 팀 앱. 모바일 위주, 스포츠 팀 느낌. 기준 화면은 인트로(풀 피치)다.
토큰은 `index.html`의 `:root`에 CSS 변수로 들어 있다. 새 화면은 raw hex 대신 토큰을 쓴다.

## 1. 컨셉
"경기장과 전광판". 장식은 축구장에서 가져온다: 잔디 줄무늬, 흰 경기장 선, 센터서클, 등번호 숫자.
한 화면에서 과감한 요소는 하나만 둔다(인트로는 경기장 선 + 큰 ATTACK).

## 2. 색 (팀컬러 고정)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--team-navy` | #1a3a6b | 기본 배경(위), 헤더, 본문 강조 글자 |
| `--team-navy-2` | #1e4d8c | 배경 그라데이션(아래) |
| `--team-deep` | #0f2850 | 더 어두운 면, 밝은 바탕 위 제목 |
| `--team-sky` | #1a7abf | 두 번째 팀 색, 링크·버튼 |
| `--team-sky-soft` | #9cc8f0 | 남색 위 보조 글자 |
| `--team-gold` | #ffd54a | 포인트(한 화면 1~2곳만) |
| `--on-team` | #ffffff | 팀 색 위 글자 |
| `--line` | 흰색 50% | 경기장 선 |
| `--turf-stripe` | 흰색 4% | 잔디 줄무늬 |

- 기본 배경: `linear-gradient(180deg, var(--team-navy), var(--team-navy-2))`
- 대비: 남색 위 흰 글자 약 10:1, sky-soft 약 6:1. 금색은 남색 위에서만 글자로 쓴다(흰 바탕 금지, 흰 바탕에는 #c98a00).
- 승/무/패: #2e7d32 / #9e9e9e / #c62828. 색만으로 구분하지 않고 글자(승·무·패, W·D·L)를 같이 쓴다.

## 3. 글꼴
| 역할 | 글꼴 | 토큰 |
|---|---|---|
| 숫자·영문 제목 | Teko 600/700 | `--font-display` |
| 한글 제목·선수 이름 | Black Han Sans | `--font-title-ko` |
| 본문 | Noto Sans KR 400~700 | (기본) |

크기 단계(모바일): 12 / 14 / 17 / 24 / 34 / 44 / 64 / 84px.
Teko는 line-height .85~1, 대문자 워드마크는 letter-spacing 6px, 작은 라벨(SINCE 2006)은 7px.
본문은 12px 미만 금지, 줄 간격 1.5 이상.

## 4. 간격·모양
- 간격: 4 / 8 / 12 / 16 / 18 / 24 / 32px. 화면 좌우 여백 16px.
- 모서리: 칩 8px, 타일 12px, 시트 18px, 히어로 카드 20px.
- 그림자: 시트 `0 1px 2px rgba(15,40,80,.05), 0 6px 18px rgba(15,40,80,.06)`, 떠 있는 요소 `0 12px 36px rgba(0,0,0,.4)`.
- 터치 영역 최소 44×44px, 요소 사이 8px 이상.
- 노치·홈바: `env(safe-area-inset-*)`를 항상 더한다.

## 5. 움직임
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease-out` | cubic-bezier(.2,.8,.2,1) | 등장 |
| `--ease-inout` | cubic-bezier(.4,0,.2,1) | 선 그리기 |
| `--ease-pop` | cubic-bezier(.2,1.3,.4,1) | 엠블럼 튀어나옴 |
| `--ease-exit` | cubic-bezier(.7,0,.3,1) | 퇴장(등장보다 빠르게) |
| `--dur-fast / base / draw` | .4s / .55s / .7s | 페이드 / 등장·퇴장 / 선 그리기 |

- 자동 재생 움직임은 화면당 한 번(인트로)만. 나머지는 사용자의 동작에 대한 반응만.
- transform·opacity·clip-path·stroke-dashoffset만 움직인다(width/height 금지).
- `prefers-reduced-motion`이면 즉시 최종 상태를 보여 주고 짧게 페이드아웃.

## 6. 인트로 규격 (기준 화면)
- 배경: 기본 배경 + 잔디 줄무늬(가로 8등분).
- 경기장: 좌우 16px, 위 18px, 아래 44px 안쪽에 2px 선. 페널티박스 폭 56%·높이 13%, 골에어리어 폭 28%·높이 5%. 하프라인은 센터서클 안도 지난다.
- 센터서클 230px, 엠블럼 150px 정가운데.
- 워드마크: "ATTACK" Teko 700 84px, 그 아래 "SINCE 2006" Teko 600 24px, sky-soft.
- 만든 사람: 오른쪽 아래 "made by redstone" 12px, 흰색 70%.
- 순서: 경기장 선(.1s) → 센터서클(.45s) → 박스(.7s) → 엠블럼(.85s) → 워드마크(1.15s) → 만든 사람(1.4s) → 위로 걷힘(2.2s). 총 약 2.7초, 누르면 즉시 닫힘. 세션당 한 번만.
- 높이 640px 이하: 서클 180px, 엠블럼 116px, 워드마크 64px.

## 7. 하지 말 것
- 팀컬러 밖의 새 강조색 추가(빨강은 패배·삭제 의미로만).
- 금색 남용, 흰 바탕 위 금색 글자.
- 같은 모양의 흰 카드를 줄줄이 쌓기(한 장의 시트 + 얇은 구분선을 쓴다).
- 12px 미만 글자, 44px 미만 버튼.
